# 能量条 HUD

屏幕底部、血条正上方的那条横条：显示当前能量 / 上限，并随职业与位阶改变外观。

## 显示条件

三个条件同时满足才画：

1. 玩家存在（`client.player != null`）
2. 没有按 F1 隐藏 HUD（`!client.options.hudHidden`）
3. **已获得职业**（`hasClass()` 为真）

没有职业时整条不画——普通人不该有力量条。

## 位置

**紧贴血条正上方**，坐标全部按原版 `InGameHud.renderStatusBars` 的公式推导，不是调出来的数字：

```java
int heartRows   = ceil((maxHealth + absorption) / 20.0F);   // 心有几排
int rowSpacing  = max(10 - (heartRows - 2), 3);             // 排间距
int topRow      = 39 + (heartRows - 1) * rowSpacing + 10;   // 最上一排距屏幕底
int y           = scaledHeight - (topRow + BAR_H);
```

默认情况（20 血、无吸收）条占 `h−59 .. h−50`，底边紧贴血条上方那一格。

**自动让位**：血量或吸收超过一排（20 点）时，原版会把上面那排顶高（吸收心多一排、盔甲行上移），本条跟着上移同样的距离，因此不会压住原版元素：

| 原版元素 | 位置 | 与本条关系 |
|---|---|---|
| 血条 | `h−39` | 在条下面，不碰 |
| 盔甲图标 | `h−49`（多排血时上移） | 在条下面，不碰 |
| 气泡 | `h−49` 附近 | 在条下面，不碰 |
| 饱食度 | `h−39` | 在条下面，不碰 |

所有坐标都是 **scaled 单位**，随 GUI 缩放等比放大，任何分辨率下比例一致。

## 尺寸

| 项 | 值 | 依据 |
|---|---|---|
| 宽 | 81 | 血条 10 颗心：`9 + 9×8 = 81`（**不是整行 182**，182 是"左血 + 右饥饿"各行共用的一整行） |
| 高 | 10 | 心形图标 9px，同一量级 |
| 边框 | 上下各 2px，左右各 1px | 外 1px 黑线 + 内 1px 白线，四角切 3px |
| 液体窗口 | 79×6 | 正好等于液体贴图尺寸 |
| 徽记 | 9×9 | 居中，覆盖第 1~9 行（第 1、8 行会压到内侧白线） |

## 贴图

全部在 `assets/mage-and-knight/textures/gui/`，**1:1 像素绘制，不缩放**：

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `energy_bar_frame.png` | 81×10 | 白框，中间窗口透明，压在液体上作遮罩 |
| `energy_bar_trough.png` | 79×6 | 空槽底（上沿压暗、下沿微亮） |
| `energy_bar_mage.png` | 79×6 | 法师液体，蓝色六阶（上亮下深） |
| `energy_bar_knight.png` | 79×6 | 骑士液体，橙色六阶 |
| `energy_bar_mythic.png` | 79×6 | 神话阶液体，亮金六阶 |
| `sigil_mage.png` | 9×9 | 法师徽记：菱形水晶 |
| `sigil_knight.png` | 9×9 | 骑士徽记：白盾 + 灰十字 |

> ⚠ **贴图尺寸与代码常量绑定**：`BAR_W` / `BAR_H` 必须等于 frame 的像素尺寸，两张液体必须是 `BAR_W−2` × `BAR_H−4`。改尺寸要图、常量一起改，否则会被拉伸、液体窗口对不上。

### 徽记的约束

- **必须 9×9**：`SIGIL_SIZE = 9` 同时用作"画多大"和"图多大"，尺寸不符会被缩放、
  像素重新分箱后糊掉。
- **背景必须透明**：徽记画在白框上面，不透明的像素会盖掉框和液体。
- **会被染色**：神话阶乘 `(1.0, 0.92, 0.62)`，建议用白色 / 灰色单色图，本身带色的图会被染脏。
- **第 9 行看不见**：画完徽记后会重画条的上下外描边，徽记最下面一行被覆盖。

## 渲染顺序

后画的盖住先画的（画家算法）：

1. 空槽贴图
2. 液体贴图 —— 只裁左边 `filled` 像素宽，`filled = 79 × current / max`
3. 白框贴图 —— 中间透明的窗口等于给液体做遮罩，液体永远画不到框上
4. 职业徽记
5. 补回首尾两行外描边（徽记 9px 会顶穿上下框）
6. 数值文本

**z 顺序**：整条在 `z = +75` 上绘制。原因：聊天框底色画在 `z = +50`、聊天文字在 `z = +100`，而普通 HUD 在 `z = 0`，深度测试用 `LEQUAL` 会让条被判成"被挡住"。抬到 +75 后能压住聊天底色，但不遮聊天文字。

## 其他行为

| 行为 | 规则 |
|---|---|
| 低能量闪烁 | `current × 4 < max`（即低于 25%）时，每 15 tick 在 `alpha = 1.0 / 0.62` 间切换，与帧率无关 |
| 数值文本 | `当前 / 上限`，画在条正上方 9px、居中；能量为 0 时用灰色 `#9AA1A9` |
| 神话阶 | 液体换金色贴图，徽记染金，**形状不变** |
| 靠右选项 | 常量 `X_ALIGN_RIGHT` 改 `true` 可贴屏幕右侧，代价是不再与血条对齐 |

## 已知限制

- **无法完全避开聊天框**：聊天底色从 `h−40` 往上、约 320 scaled px 宽，而"血条正上方"这一片必然落在其中。已用 z 顺序解决遮挡，但位置本身仍在聊天区域内。
- **徽记压白线**：9px 徽记在 10px 条上，会让内侧白线在中间出现约 7px 的缺口。缩到 6×6 可完全避免，但图案会变得极简。
